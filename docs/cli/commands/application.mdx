## Overview

Deploy and manage applications within your Qovery environment.

## Commands

### List Applications

List all applications in current environment:

```bash
qovery application list
```

Output as JSON:

```bash
qovery application list --json
```

### Deploy Application

Deploy a specific application:

```bash
qovery application deploy --application "my-api"
```

Deploy with a specific commit:

```bash
qovery application deploy \
  --application "my-api" \
  --commit-id "abc123def"
```

Deploy the newest commit of the branch with `latest`. The CLI resolves it to a commit SHA, prints the resolved SHA, and deploys it:

```bash
qovery application deploy \
  --application "my-api" \
  --commit-id latest
```

Deploy multiple applications at once:

```bash
qovery application deploy \
  --applications "app1,app2,app3"
```

Watch deployment progress:

```bash
qovery application deploy \
  --application "my-api" \
  --watch
```

### Redeploy Application

Redeploy the same version:

```bash
qovery application redeploy --application "my-api"
```

Redeploy a specific commit, or the newest commit of the branch with `latest`. When `--commit-id` is omitted, the currently deployed commit is reused:

```bash
qovery application redeploy --application "my-api" --commit-id "a1b2c3d"
qovery application redeploy --application "my-api" --commit-id latest
```

### Restart Application

Restart a running application without redeploying it:

```bash
qovery application restart --application "my-api"
```

Restart multiple applications and wait until they are restarted:

```bash
qovery application restart \
  --applications "app1,app2" \
  --watch
```

<Note>
With `--watch`, the command follows only the selected applications and exits with code 1 if one of them fails, is canceled, or no longer exists.
</Note>

### Stop Application

Stop a running application:

```bash
qovery application stop --application "my-api"
```

Stop multiple applications:

```bash
qovery application stop --applications "app1,app2"
```

### Cancel Deployment

Cancel an ongoing deployment:

```bash
qovery application cancel --application "my-api"
```

### Delete Application

Delete an application:

```bash
qovery application delete --application "my-api"
```

### Update Application

Update application configuration (branch or auto-deploy setting):

```bash
qovery application update \
  --application "my-api" \
  --branch "main"
```

Enable auto-deploy:

```bash
qovery application update \
  --application "my-api" \
  --auto-deploy
```

## Examples

### Deploy Application

```bash
# Set context first if not already set
qovery context set

# Deploy latest commit
qovery application deploy --application "my-api"

# Deploy with specific commit
qovery application deploy \
  --application "my-api" \
  --commit-id "a1b2c3d"

# Watch deployment progress
qovery application deploy \
  --application "my-api" \
  --watch
```

### Deploy Multiple Applications

```bash
qovery application deploy \
  --applications "frontend,backend,worker"
```

### Rollback Deployment

```bash
# Deploy a previous commit
qovery application deploy \
  --application "my-api" \
  --commit-id "previous-commit-sha"
```

### Update Branch

```bash
qovery application update \
  --application "my-api" \
  --branch "feature/new-branch"
```

## Additional Subcommand Groups

The `application` command also has the following subcommand groups for more advanced management:

- **`qovery application clone`**: clone an application to another environment
- **`qovery application domain`**: manage custom domains (`list`, `create`, `delete`, `edit`)
- **`qovery application env`**: manage environment variables and secrets (`list`, `create`, `update`, `delete`, `alias`, `override`)
- **`qovery application external-secret`**: manage external secrets (`create`, `update`, `delete`)
