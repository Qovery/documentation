## Overview

Use `qovery terraform` to run and manage the Terraform services of an environment from the terminal: list them, run a plan, plan and apply, delete their resources, unlock or migrate their state, and manage their external secrets.

## Examples

List the Terraform services of an environment:

```bash
qovery terraform list \
  --organization "Acme Corp" \
  --project "Backend Services" \
  --environment "production"
```

Run a plan without applying it, and follow it until it finishes:

```bash
qovery terraform plan --terraform "network" --watch
```

Plan and apply the newest commit of the branch:

```bash
qovery terraform plan-and-apply \
  --terraform "network" \
  --commit-id latest \
  --watch
```

Plan and apply several Terraform services at once:

```bash
qovery terraform plan-and-apply --terraforms "network,database"
```

### Access the Terraform state

`setup-backend` generates a `backend.tf` file that points Terraform at the state Qovery stores for a Terraform service. The command asks before it writes the file in the current directory.

`--terraform` (`-t`) takes the **ID** (UUID) of the Terraform service, not its name. Without it, the command uses the service in the current [context](/cli/commands/context).

```bash
qovery terraform setup-backend --terraform "<terraform-service-id>"
```
