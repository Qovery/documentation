## Overview

Use `qovery organization` to see which organizations the current login or API token can access. The table shows the ID, name and plan of each organization.

## Examples

List organizations:

```bash
qovery organization list
```

Get the list as JSON, for example to read organization IDs in a script:

```bash
qovery organization list --json
```
