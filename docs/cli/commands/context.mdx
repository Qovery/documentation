## Overview

The `context` command manages your current working context (organization, project, environment). This allows you to run commands without specifying these parameters every time.

## Commands

### Show the current context

```bash
qovery context
```

Prints the organization, project, environment and service the CLI currently targets.

### Set the context

```bash
qovery context set
```

`qovery context set` is an interactive picker: it asks you to select an organization, then a
project, an environment and a service. It takes no flags.

<Note>
**Scripts, CI and AI agents** cannot answer the interactive picker. Skip the context and pass names
explicitly instead: commands accept `--organization`, `--project` and `--environment` (for example
`qovery environment list --organization "Acme Corp" --project "Backend Services"`), and
`qovery api` takes IDs in the path (`qovery api organization/<org-id>/project`).
</Note>

## Examples

### Switch to another organization, project or environment

```bash
qovery context set
# Select organization -> project -> environment -> service
qovery context
# Check what is now selected
```

### Target an organization without changing the context

```bash
qovery project list --organization "Acme Corp"
```
