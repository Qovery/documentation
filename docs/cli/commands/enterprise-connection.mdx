## Overview

Use `qovery enterprise-connection` to view and update the [SSO](/configuration/organization/sso) enterprise connection of an organization, and to map identity provider (IdP) groups to Qovery roles.

- `get` and `update` read and change the connection: its default role for new users and whether group synchronization is enforced.
- `group-mappings` lists, adds or changes, and deletes the mappings between IdP groups and Qovery roles.

`--qovery-role` and `--default-role` take the name of a [role](/configuration/organization/members-rbac), built-in or custom. The name is not case-sensitive.

## Examples

Show an enterprise connection:

```bash
qovery enterprise-connection get \
  --organization "Acme Corp" \
  --connection "$CONNECTION_NAME"
```

Set the default role for new users and enforce group synchronization:

```bash
qovery enterprise-connection update \
  --organization "Acme Corp" \
  --connection "$CONNECTION_NAME" \
  --default-role "viewer" \
  --enforce-group-sync
```

List the group mappings:

```bash
qovery enterprise-connection group-mappings get \
  --organization "Acme Corp" \
  --connection "$CONNECTION_NAME"
```

Map two IdP groups to a Qovery role:

```bash
qovery enterprise-connection group-mappings add \
  --organization "Acme Corp" \
  --connection "$CONNECTION_NAME" \
  --qovery-role "admin" \
  --idp-group-names "platform-team,sre"
```

Remove the mapping of a role:

```bash
qovery enterprise-connection group-mappings delete \
  --organization "Acme Corp" \
  --connection "$CONNECTION_NAME" \
  --qovery-role "admin"
```
