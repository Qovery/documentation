## Overview

Use `qovery version` to check which version of the Qovery CLI is installed, for example before reporting an issue or to compare it with the [latest release](https://github.com/Qovery/qovery-cli/releases).

## Example

```bash
qovery version
```

Output:

```
Info: 1.180.0
```
