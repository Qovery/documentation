## Overview

Use `qovery webhook` to list the [webhooks](/configuration/integrations/webhooks) of an organization and check the events each webhook sent, with the target URL, response status code and response body.

## Examples

List the webhooks of an organization:

```bash
qovery webhook list --organization "Acme Corp"
```

List the events sent by one webhook. `--webhook-id` is required; take the ID from `qovery webhook list`:

```bash
qovery webhook list-event \
  --organization "Acme Corp" \
  --webhook-id "$WEBHOOK_ID"
```

Get the events as JSON, including the payload sent:

```bash
qovery webhook list-event --organization "Acme Corp" --webhook-id "$WEBHOOK_ID" --json
```
