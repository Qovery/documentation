## Overview

Use `qovery upgrade` to update the CLI to the latest release. The command checks for a newer version, downloads it from the [Qovery CLI releases](https://github.com/Qovery/qovery-cli/releases) on GitHub and replaces the current binary. If you already run the latest version, it says so and changes nothing.

The command needs write permission on the CLI binary file. If it does not have it, the upgrade is cancelled and the error shows the path of the binary.

<Note>
`qovery upgrade` is not included in the Windows build of the CLI. On Windows, install the new version the same way you installed the CLI.
</Note>

## Example

```bash
qovery upgrade
```

Check the result:

```bash
qovery version
```
