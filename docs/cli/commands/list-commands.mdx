## Overview

Use `qovery list-commands` to print the whole command tree in one go: every command and subcommand with its description, aliases, usage when it takes arguments, and each flag with its type and default value. It is handy to search for a flag, or to give a script or an AI agent the full list of commands.

## Examples

Print all commands:

```bash
qovery list-commands
```

Find the flags of one subcommand:

```bash
qovery list-commands | grep -A 8 "application deploy:"
```

Part of the output:

```
Available commands:
  api: Make an authenticated request to the Qovery API
    Usage: qovery api <endpoint> [flags]
    Flag: -f, --field (stringArray), default: []
    Flag: -H, --header (stringArray), default: []
```
