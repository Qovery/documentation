---
title: "API Token"
description: "Manage API tokens for programmatic access to your organization"
---

An API Token is used by third-party applications or scripts to access to your organization via the Qovery API (CI/CD, Terraform, Pulumi, etc.).

You can manage API tokens attached to your organization directly from the Qovery Console or using the [Qovery CLI](/cli/commands/token).

<Note>
  Qovery offers a second kind of token. An **API Token** carries a
  [role](/configuration/organization/members-rbac) and is the right choice for
  CI/CD, Terraform and scripts. An
  [**API Policy Token**](/configuration/organization/api-policy-token) carries no
  role but a policy evaluated on every request, and is meant for autonomous
  agents that need a narrower footprint than any role can express.
</Note>

## Create a New Token

<Tabs>
  <Tab title="Console">
<Steps>
  <Step title="Click Add new Button">
    Press the **Add new** button to create a new API token
  </Step>

<Step title="Configure Token">
  Provide the following information: - **Name**: A descriptive name for the
  token - **Description**: Purpose or usage details - **Role**: Select a role
  managed via the [Qovery RBAC system](/configuration/organization/members-rbac)
</Step>

  <Step title="Save Token">
    After creation, the token will be displayed once
  </Step>
</Steps>
  </Tab>

  <Tab title="CLI and API">
    You need the [Qovery CLI](/cli/overview), signed in with `qovery auth`.

    Run `qovery token`. It asks for the organization, a name, a description and a role, then prints the token once:

    ```bash
    qovery token
    ```

    With the API, get the role ID from `GET /organization/{organizationId}/availableRole`, then call `POST /organization/{organizationId}/apiToken`. `name` and `role_id` are required:

    ```bash
    qovery api organization/<organizationId>/availableRole

    qovery api organization/<organizationId>/apiToken \
      --field name=ci-deployer \
      --field description="GitHub Actions" \
      --field role_id=<roleId>
    ```

    The response contains the token value. It is returned only once.
  </Tab>

  <Tab title="Terraform">
    Use the [`qovery_api_token`](https://registry.terraform.io/providers/Qovery/qovery/latest/docs/resources/api_token) resource. `organization_id`, `name` and `role_id` are required:

    ```hcl
    resource "qovery_api_token" "ci" {
      organization_id = "<organizationId>"
      name            = "ci-deployer"
      description     = "GitHub Actions"
      role_id         = "<roleId>"
    }
    ```

    The token value is in the sensitive `token` attribute. It is only known at creation and is stored in the Terraform state, so use an encrypted remote state with restricted access. Any attribute change replaces the token.
  </Tab>
</Tabs>

### Check it worked

List the tokens of the organization:

```bash
qovery api organization/<organizationId>/apiToken
```

The new token appears with its `name` and `role_name`. To confirm the token itself works, call the API with it:

```bash
curl -H "Authorization: Token $QOVERY_API_TOKEN" https://api.qovery.com/organization
```

The response lists the organizations the token can access.

<Warning>
  **Important**: Make sure you safely store the token returned by the UI. You
  won't be able to retrieve it again (you will have to create a new one).
</Warning>

## Review Token Usage

Each token in the Token API list shows its role, its creation date, and **Last used**, the time elapsed since the token was last used, for example "Last used 3 days ago". Hover over it to see the exact date and time in UTC. Use it to identify tokens that are no longer in use before you delete them. The **Last used** label is not displayed when no usage has been recorded for the token.

## Delete a Token

To remove an API token:

1. Locate the token in the Token API list
2. Click the **delete icon** (trash icon) next to the token
3. Confirm the deletion

With the API, call `DELETE /organization/{organizationId}/apiToken/{apiTokenId}`. Token IDs come from `GET /organization/{organizationId}/apiToken`.
