## Overview

Use `qovery status` to check the state of one service: the application or container selected in your [context](/cli/commands/context). If no service is selected, the command asks you to pick the organization, project, environment and service first.

The command takes no flags. To check another service, change the context with `qovery context set`. For other service types, or to see all services of an environment, use [`qovery service list`](/cli/commands/service).

## Examples

Check the status of the service in the current context:

```bash
qovery status
```

Output:

```text
Application | Status
my-api      | DEPLOYED
```

Check another service:

```bash
qovery context set
qovery status
```

The status is the service state from the Qovery API, for example `DEPLOYED`, `DEPLOYING`, `BUILDING`, `STOPPED` or `DEPLOYMENT_ERROR`.
