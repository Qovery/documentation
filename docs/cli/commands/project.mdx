## Overview

Use `qovery project` to list the projects of an organization and to manage project-level environment variables and secrets, which every environment of the project inherits.

## Commands

### List Projects

List all projects in current organization:

```bash
qovery project list
```

### Manage Project Variables

The `project env` subgroup provides commands to manage project-level environment variables and secrets.

```bash
qovery project env list --project "my-project"
```

## Examples

### List Projects

```bash
# Set organization context
qovery context set

# List projects
qovery project list

# List projects as JSON
qovery project list --json
```

### List Project Variables

```bash
qovery project env list --project "my-project"

# Show values
qovery project env list --project "my-project" --show-values
```

### Create a Project Secret

```bash
qovery project env create \
  --project "my-project" \
  --key "API_KEY" \
  --value "$API_KEY" \
  --secret
```
