Each guide takes one framework from a Git repository to a running application on a Kubernetes cluster in your own cloud account. It covers a production Dockerfile, the port and health check, a PostgreSQL database wired through `DATABASE_URL`, migrations in a lifecycle job, the deployment from the Console or with a coding agent, and the errors people hit most.

For another language, start from [Write a Dockerfile](/getting-started/guides/advanced-tutorials/write-dockerfile), or ask your coding agent to deploy the repository with the [Qovery Agent Skills](/getting-started/quickstart/agent-skills).
