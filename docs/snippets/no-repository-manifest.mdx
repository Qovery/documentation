<Note>
**No configuration file in your repository.** Qovery does not read a `qovery.yml`, `.qovery.yml` or `.qovery.toml`, and there is no `qovery init`. Projects, environments and services are created in the Console, with `qovery api`, or with [Terraform](/terraform-provider/overview). For the full path from a repository to a running app with commands only, see [Deploy with the CLI and API](/getting-started/quickstart/cli-and-api).
</Note>
