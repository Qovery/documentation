## Overview

Use `qovery blueprint` to move a [blueprint](/configuration/blueprints) service to the latest tag of a newer major version, for example PostgreSQL 14 to 18.

The command is built for AWS RDS PostgreSQL databases. Other blueprint services are accepted, but Qovery does not check that their new major can be applied safely, so review that template's upgrade notes first. See [Point a Blueprint at a Newer Major Version](/cli/overview#point-a-blueprint-at-a-newer-major-version) for what each kind of move does.

## Examples

List the newer majors and what moving to each one would do:

```bash
qovery blueprint upgrade-major --name "my-postgres"
```

Move to major 18, skip the confirmation prompt and follow the deployment:

```bash
qovery blueprint upgrade-major \
  --name "my-postgres" \
  --major 18 \
  --yes \
  --watch
```

<Warning>
An in-place major upgrade takes the database offline while AWS upgrades it. For a production database, upgrade with an [AWS Blue/Green deployment](/getting-started/guides/advanced-tutorials/upgrading-rds-instance) first, then run the command: it only relabels the blueprint.
</Warning>
