## Overview

Manage the organizations your authenticated token has access to.

## Commands

### List Organizations

List all organizations the currently authenticated token can access:

```bash
qovery organization list
```

The output lists each organization's ID, name, and plan.

**Flags:**

| Flag | Description |
|------|-------------|
| `--json` | JSON output |
| `--help` | Show help for the command |

## Examples

### List Organizations

```bash
# List organizations in a table
qovery organization list

# List organizations as JSON (useful for scripting)
qovery organization list --json
```

### Retrieve an Organization ID for Scripting

```bash
# Get the ID of the first organization
qovery organization list --json | jq -r '.[0].id'
```
