## Overview

Use `qovery help` to print the usage, subcommands and flags of any command. `qovery help <command>` shows the same text as `qovery <command> --help`.

## Examples

Show the list of all commands:

```bash
qovery help
```

Show help for a command:

```bash
qovery help application
```

Show help for a subcommand:

```bash
qovery help application deploy
```

The same, with the `--help` flag:

```bash
qovery application deploy --help
```
