## Overview

A project allows you to group together a set of environments with the objective to run the same application. Projects are automatically created when you create a new organization and support role-based access control through [Qovery's RBAC system](/configuration/organization/members-rbac).

## Prerequisites

- An existing organization in Qovery

## Create a New Project

<Tabs>
  <Tab title="Console">
<Steps>
  <Step title="Open Organization Overview">
    Go to your organization overview in the [Qovery Console](https://console.qovery.com)
  </Step>

  <Step title="Create Project">
    Click the **New Project** button

    ![Project Creation](/images/configuration/project/project_creation.png)
  </Step>

  <Step title="Configure Project">
    Enter the following information:
    - **Name**: A descriptive name for your project
    - **Description**: (Optional) Brief description of the project's purpose
  </Step>

  <Step title="Save">
    Click **Create** to finalize the project creation
  </Step>
</Steps>
  </Tab>

  <Tab title="CLI and API">
    You need the [Qovery CLI](/cli/overview), signed in with `qovery auth`, and `jq` to read the IDs that the API returns. The `qovery api` command sends authenticated requests to the [Qovery API](/api-reference/introduction).

    Create the project with `POST /organization/{organizationId}/project`. Only `name` is required:

    ```bash
    ORGANIZATION_ID="REPLACE_WITH_ORGANIZATION_ID"  # from qovery organization list --json

    PROJECT_ID=$(qovery api "organization/$ORGANIZATION_ID/project" \
      --field name=my-project \
      --field description="Backend services" | jq -r .id)
    echo "$PROJECT_ID"
    ```

    The command stores the new project ID in `PROJECT_ID`.
  </Tab>

  <Tab title="Terraform">
    Use the [`qovery_project`](https://registry.terraform.io/providers/Qovery/qovery/latest/docs/resources/project) resource. `name` and `organization_id` are required:

    ```hcl
    resource "qovery_project" "my_project" {
      organization_id = "<organizationId>"
      name            = "my-project"
      description     = "Backend services"
    }
    ```

    Run `terraform apply` to create the project.
  </Tab>
</Tabs>

### Check it worked

List the projects of the organization selected in your CLI context (set it with `qovery context set`):

```bash
qovery project list
```

The new project appears in the list. With the API, `GET /organization/{organizationId}/project` returns it in `results`.

## Edit Project General Information

To update project details:

<Tabs>
  <Tab title="Console">
<Steps>
  <Step title="Access Settings">
    Open the project settings page
  </Step>

  <Step title="Select Project">
    Choose the project you want to edit
  </Step>

  <Step title="Open General Section">
    Navigate to the **GENERAL** section
  </Step>

  <Step title="Update and Save">
    Modify the name or description and save your changes

    ![Project Update](/images/configuration/project/project_update.png)
  </Step>
</Steps>
  </Tab>

  <Tab title="CLI and API">
    Send the new values with `PUT /project/{projectId}`. `name` is required, even if you only change the description. You need the admin permission on the project.

    ```bash
    PROJECT_ID="REPLACE_WITH_PROJECT_ID"  # from qovery project list

    qovery api "project/$PROJECT_ID" --method PUT \
      --field name=my-project \
      --field description="New description"
    ```
  </Tab>

  <Tab title="Terraform">
    Change `name` or `description` in your `qovery_project` resource and run `terraform apply`.
  </Tab>
</Tabs>

## Delete a Project

<Warning>
Deleting a project is a **non-recoverable operation**. This will permanently delete:
- All environments within the project
- All running applications and their data
- All databases and their data
- All configuration and secrets
- All deployment history
</Warning>

To delete a project:

<Tabs>
  <Tab title="Console">
<Steps>
  <Step title="Access Project Settings">
    Open the project settings page
  </Step>

  <Step title="Select Project">
    Choose the project you want to delete
  </Step>

  <Step title="Navigate to Danger Zone">
    Go to the **DANGER** section
  </Step>

  <Step title="Delete Project">
    Click the **Delete Project** button

    ![Project Delete](/images/configuration/project/project_delete.png)
  </Step>

  <Step title="Confirm Deletion">
    Type the project name to confirm and complete the deletion
  </Step>
</Steps>
  </Tab>

  <Tab title="CLI and API">
    Delete the project with `DELETE /project/{projectId}`. You need the admin permission on the project.

    ```bash
    PROJECT_ID="REPLACE_WITH_PROJECT_ID"  # from qovery project list

    qovery api "project/$PROJECT_ID" --method DELETE
    ```

    Run `qovery project list` afterwards: the project is no longer listed.
  </Tab>

  <Tab title="Terraform">
    Remove the `qovery_project` resource from your configuration and run `terraform apply`, or run `terraform destroy -target=qovery_project.my_project`.
  </Tab>
</Tabs>
