Qovery is an Agentic DevOps platform that runs in your own cloud account (AWS, GCP, Azure, or Scaleway) or on any Kubernetes cluster you already run. Tell your AI agent to deploy, or use the console, CLI, and Terraform. Everything drives the same Kubernetes control plane.

Choose your deployment path. To try Qovery first, sign in with `qovery auth`, pick your organization with `qovery context set`, then run `qovery demo up`: it installs the Qovery Operator on a local k3s cluster with Docker. See [Test & Learn Locally](/getting-started/quickstart/docker).
