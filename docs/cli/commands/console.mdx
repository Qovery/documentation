## Overview

Use `qovery console` to jump from the terminal to the Qovery Console page of a service. The command opens the service selected in your [context](/cli/commands/context) in your default browser and prints the URL it opens.

If no organization, project, environment or service is selected yet, the command asks you to pick them first. The command takes no flags and no arguments: to open another service, change the context with `qovery context set`.

## Examples

Open the service in the current context:

```bash
qovery console
```

Open another service:

```bash
qovery context set
qovery console
```

## Tips

<Tip>
Use `qovery console` when you need to perform actions that are easier in the web interface, like viewing metrics or managing complex configurations.
</Tip>
