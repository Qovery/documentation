---
title: "BYOK (Bring Your Own Kubernetes)"
description: "Connect your own AWS, GCP or Scaleway Kubernetes cluster to Qovery"
tag: "PREVIEW"
---

Connect a Kubernetes cluster you already run to Qovery by installing the Qovery Operator. Qovery then installs and updates the Qovery stack on the cluster.

<Note>
Another provider, an on-premise cluster or the local demo? Follow the [installation with the Qovery CLI](/configuration/integrations/kubernetes/byok-legacy).
</Note>

<Info>
Want Qovery to provision and manage the cluster for you instead? See [Create Your Cluster](/getting-started/quickstart/cloud) for the managed path (AWS, GCP, Azure, Scaleway).
</Info>

<Info>
The Qovery Operator installation is in Preview: see its [prerequisites and current limitations](/configuration/integrations/kubernetes/byok#current-limitations).
</Info>

## Prerequisites

<Check>A Qovery organization on a plan that includes self-managed clusters (Professional, Business or Enterprise)</Check>
<Check>A running Kubernetes cluster on AWS (EKS), GCP (GKE) or Scaleway (Kapsule), with at least one node that has 4 vCPU and 8 GiB of memory free for builds, for example an 8 vCPU node</Check>
<Check>`kubectl` access to the cluster with `cluster-admin` rights and `helm`, only to install the Operator once</Check>
<Check>A cloud credential for the provider of the cluster, with the [required permissions](/configuration/integrations/kubernetes/byok#credential-permissions)</Check>
<Check>Active Qovery account - [Sign up here](https://start.qovery.com)</Check>

## Installation

<Steps>
  <Step title="Create the cluster in the Console">
    Go to **Clusters**, add a cluster and, under **Connect existing cluster (BYOK)**, select **AWS**, **GCP** or **Scaleway**. Fill in the cluster name, the credential and the region.
  </Step>

  <Step title="Install the Qovery Operator">
    Download the Helm values file and run the Helm command shown in the Console, with a kubeconfig pointing to your cluster. Keep the page open: the Console opens the cluster profile once the Operator connects.
  </Step>

  <Step title="Deploy the platform profile">
    Review the profile settings. Click **Save and deploy** if you changed one, or **Deploy** in the **Manage deployment** menu of the cluster to keep the defaults. Qovery installs the Qovery stack on the cluster.
  </Step>
</Steps>

See [Bring Your Own Kubernetes (BYOK)](/configuration/integrations/kubernetes/byok) for each step in detail.
