## Overview

Use `qovery audit-log export` to download the audit logs of an organization to a CSV file named `audit_logs_<date>_<time>.csv` in the current directory. The command first prints how many days of history your organization plan keeps.

`--from-date` is required. Dates must use the ISO-8601 format with a `T` between the date and the time, and a time zone, for example `2026-10-01T00:00:00Z` or `2026-10-01T02:00:00+02:00`. Without `--to-date`, the export runs until now.

## Examples

Export from a date until now:

```bash
qovery audit-log export \
  --organization "Acme Corp" \
  --from-date "2026-10-01T00:00:00Z"
```

Export a date range:

```bash
qovery audit-log export \
  --organization "Acme Corp" \
  --from-date "2026-10-01T00:00:00Z" \
  --to-date "2026-10-31T23:59:59Z"
```
