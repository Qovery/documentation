## Overview

Use `qovery list-pods` to see which pods a service runs and which ports each pod exposes, for example to pick a pod for [`qovery port-forward`](/cli/commands/port-forward) or [`qovery shell`](/cli/commands/shell).

Without an argument, the command shows the current [context](/cli/commands/context) and asks whether to use it. If you answer no, or no service is selected, it asks you to pick the organization, project, environment and service. You can also pass the Console URL of the service instead.

## Examples

List the pods of the service in the current context:

```bash
qovery list-pods
```

List the pods of a service from its Console URL:

```bash
qovery list-pods "https://console.qovery.com/organization/$ORG_ID/project/$PROJECT_ID/environment/$ENV_ID/application/$APP_ID"
```

The output is a table with a `Pod Name` column and a `Ports` column, one row per pod. A pod that exposes several ports lists them separated by commas:

```text
Pod Name               | Ports
my-api-6d4f9c7b8-x2k9p | 8080
```
